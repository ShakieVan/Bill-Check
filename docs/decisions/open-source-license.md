# Open-Source-Lizenz

Stand: 16.08.2026

## Entscheidung

Bill Check wird unter der GNU General Public License Version 3 veröffentlicht.
Die eindeutige SPDX-Kennung lautet `GPL-3.0-only`; eine automatische
Erweiterung auf spätere Lizenzversionen wird damit nicht eingeräumt.

Der kanonische Lizenztext liegt im Wurzelverzeichnis als [`LICENSE`](../../LICENSE).
Quellcode, öffentliche Dokumentation, Release Notes, APKs und Prüfsummen
gehören in `ShakieVan/Bill-Check`.

## Private Daten

Reale Hotelbelege, Zwischen- und Endrechnungen sowie sonstige persönliche
Testbilder gehören ausschließlich in das private Repository
`ShakieVan/Bill-Check-Data`. API-Schlüssel, Signierschlüssel und deren
Passwörter werden ebenfalls nie veröffentlicht.

## Konsequenz

Wer die App oder abgeleitete Fassungen weitergibt, muss die Bedingungen der
GPL Version 3 erfüllen und den korrespondierenden Quellcode unter derselben
Lizenz zugänglich machen. Die Lizenzentscheidung betrifft nicht die privaten
Testbilder oder persönliche Datenbestände.
